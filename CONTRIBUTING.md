# Contributing to Awesome AI HTML Games

Thanks for helping grow this open catalog of single-file AI-generated HTML games and interactive web demos!

## Fastest Way: Submit Directly Online

1. Open **[https://ahanow.ai/showcase?submit=1](https://ahanow.ai/showcase?submit=1)**.
2. Upload your self-contained `.html` file (up to 32 MB).
3. Include:
   - **Title** and a crisp one-line **summary**
   - **AI model used** (e.g., `Claude Opus 5.5`, `Gemini 4`, `GPT-5`)
   - **Category** (e.g., `3D Arcade`, `Physics Sandbox`, `Puzzle`, `Audio Visualizer`)
   - **Author name**, **author/source link** (X / GitHub / personal site), and **license** (e.g., `MIT`)
4. Once approved, your creation receives a permanent playable sandbox page at `https://ahanow.ai/showcase/<slug>` and is automatically synced into this repository.

## Pull Request Guidelines

- Only submit playable, self-contained HTML creations with clear attribution to the original author.
- Keep descriptions factual and concise (what it does, controls, and rendering/audio tech used).
- Do not include spam, trackers, or copyrighted assets without permission.
